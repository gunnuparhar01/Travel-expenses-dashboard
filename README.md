# Traval Expense Analysis Dashboard

This project analyze travel expenses using Excel dashboard and visualization .

## Tool used: 
- Microsoft Excel,
- Pivot Table,
- Pivot Charts,
- Slicers

## Dashboard Features-
- Total Trip analysis
- Monthly expense trend
- Destination-wise spending 
- Category-wise expense analysis

## Skills Demonstrated-
- Data visualization 
- Dashboard creation 
- Data analysis
- Interactive reporting
